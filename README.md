# Royaly Developer Website

A responsive, dependency-free recreation of the Royaly Developer landing page.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Features

- Responsive editorial architecture portfolio
- Scroll-triggered reveal animations
- Hero parallax and cursor glow
- Animated mobile navigation
- Interactive before/after comparison
- Reduced-motion accessibility support
- Original image assets from the reference site
